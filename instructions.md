# Welcome to your new project Python! Follow through the steps below to start

## Recommended tools

1. Python3;
2. Git;
3. VS Code;
4. VS Code Python Extension (should auto install Pylance, Python Debugger, and Python Environments).

## Setting up your project environment

1. Open this folder;
2. On the Powershell Terminal, run `uv init --no-pin-python` to start the project with support to python version changes, and to write a first `.toml` file to the folder;
3. Then run `uv add module1 module2 moduleN;;uv sync` with the list of modules needed for your project.
